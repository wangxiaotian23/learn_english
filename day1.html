Day 1

每日站会 Daily Standup

站会是 IT 职场每天必开口的场景。今天掌握 yesterday–today–blockers 三段式汇报，这是最值得先练熟的一套句型。

今日目标

  1. 能用三句话流畅汇报：昨天做了什么、今天打算做什么、有没有阻塞。
  2. 掌握描述「进度」和「阻塞」的核心句型各 5 个以上。
  3. 能听懂并回应别人的简短追问（如 "When can it be done?"）。

核心句型

① 汇报昨天（Yesterday）

Yesterday, I finished implementing the login API.
昨天我完成了登录接口的开发。
已完成 · finished / completed / wrapped up
I spent most of the day debugging the payment issue.
我昨天大部分时间在排查支付问题。
花时间做某事 · spent...doing
I was working on the reporting module, and it's about 80% done.
我在做报表模块，大概完成了 80%。
进行中 + 进度百分比
I picked up the ticket from the backlog and got it code-reviewed.
我领了待办里的工单，并完成了代码评审。
领任务 · picked up a ticket

② 汇报今天（Today）

Today, I'm going to work on the search feature.
今天我打算做搜索功能。
be going to + 动词
My focus today is to get the bug fix deployed to staging.
今天的重点是把修复部署到测试环境。
聚焦 · My focus today is...
I plan to finish the code review by end of day.
我计划在今天下班前完成代码评审。
截止时间 · by end of day (EOD)
I'll continue with the migration and hopefully wrap it up tomorrow.
我会继续做迁移，希望明天能收尾。
继续做 · continue with

③ 汇报阻塞（Blockers）

No blockers on my side.
我这边没有阻塞。
一切正常 · 最常用短句
I'm blocked on the API — it hasn't been deployed to the test environment yet.
我被接口卡住了——它还没部署到测试环境。
被阻塞 · be blocked on...
I'm waiting on the design team to confirm the specs.
我在等设计团队确认需求细节。
等待他人 · waiting on someone
I might need help from the backend team to figure out the root cause.
我可能需要后端团队帮忙找出根本原因。
求助 · need help to...
Could we sync after standup? I'd like to walk you through the details.
站会后我们能对一下吗？我想给你讲一下细节。
把深入讨论移出站会

情景对话

场景一：常规站会，按 yesterday–today–blockers 汇报

Scrum MasterMorning, everyone. Let's get started — quick round of updates. Alex, do you want to kick us off?早上好。我们开始吧，快速过一轮进展。Alex，你先来说？
你Sure. Yesterday I finished implementing the login API and opened a pull request. I also paired with Kevin in the morning to debug the flaky integration tests — turns out it was a race condition in the test setup, and we fixed it.好的。昨天我完成了登录接口开发并提了 PR。上午还和 Kevin 结对排查了不稳定的集成测试——发现是测试环境搭建里的竞态条件，已经修好了。
你Today I'm going to work on the token refresh logic, and if time permits, I'll start writing unit tests for the login flow.今天我打算做 token 刷新逻辑，如果时间够，就开始给登录流程写单元测试。
你No blockers on my side, but the PR is still waiting for a review — Tom, do you think you can get to it today?我这边没有阻塞，不过 PR 还在等评审——Tom，你今天能看一下吗？
TomYeah, I'll take a look right after standup. Should be quick since you left good commit messages.可以，站会后我就看。你提交信息写得很清楚，应该很快。
Scrum MasterGreat. When can we expect it to be merged?很好。预计什么时候能合进去？
你Probably by end of day, as long as the review doesn't turn up anything major.大概今天下班前，只要评审没有发现大问题。
Scrum MasterSounds good. Thanks, Alex. Next up...好的，谢谢 Alex。下一位……

场景二：有阻塞时的汇报，包含追问和求助

你Quick update from me. Yesterday I spent most of the day debugging the payment failure on production. It turns out the third-party sandbox has been down since Tuesday, so I couldn't reproduce the issue locally.我简单汇报一下。昨天大部分时间在排查生产环境的支付失败。发现第三方沙箱从周二就挂了，所以我一直没法在本地复现。
Tech LeadDo we have a support ticket open with the vendor?我们给供应商开工单了吗？
你Yes, I raised one yesterday afternoon, but we haven't heard back yet. So I'm blocked on that for now — I can't verify the fix until the sandbox is back up.开了，我昨天下午提的工单，但还没有回复。所以这块我被卡住了——沙箱恢复之前没法验证修复。
Tech LeadGot it. In the meantime, could you look into adding better error logging around the payment flow? That way we'll have more data when it happens again.了解了。那这段时间能不能给支付流程加上更完善的错误日志？这样下次出问题我们就有更多数据。
你Sure, I can do that. I'll also write up a short summary of what we know so far and post it in the channel, so everyone's on the same page.可以。我还会把我们目前的发现写个简短总结发到频道里，让大家信息同步。
Tech LeadPerfect. And if the vendor doesn't respond by tomorrow, ping me — I have a contact on their side.很好。如果明天供应商还没回复，喊我一声——我那边有他们的联系人。
你Will do. Could we also sync with Lisa after standup? She owns the monitoring dashboard, and I'd like to walk her through the error patterns we're seeing.好的。站会后能和 Lisa 对一下吗？监控面板是她负责的，我想给她讲一下我们看到的报错规律。
Tech LeadYeah, go ahead and set up a quick 15-minute call.可以，你们约个 15 分钟的短会就行。

场景三：进度落后的汇报（诚实 + 有预案）

Scrum MasterAlex, you're up. How's the search feature coming along?Alex，到你了。搜索功能进展怎么样？
你To be honest, it's a bit behind. I underestimated the work needed for the indexing part. The basic search works, but relevance tuning is taking longer than expected.说实话，进度有点落后。我低估了索引部分的工作量。基础搜索已经能跑，但相关性调优比预期慢。
Scrum MasterHow far behind are we talking?大概会晚多少？
你Originally I said this Friday. Realistically, I can have a working version by Friday, but the polished version won't be ready until next Wednesday.原来说这周五。实际一点，周五我能交一个可用版本，但打磨完成的版本要到下周三。
你One option is to descope the advanced filters and ship the core search first. I'd like to hear your thoughts.一个办法是把高级筛选移出本期范围，先上核心搜索。想听听大家的意见。
Scrum MasterGood thinking. Let's discuss it in the grooming session this afternoon — no need to solve it here.思路不错。我们下午的需求梳理会上再讨论——不用在站会上解决。
你Sounds good. I'll add it to the agenda.好的，我把它加到议程里。
对话里的高频「接话」表达：
· Turns out (that)... —— 结果发现是……（排查问题必备）
· Got it. / Understood. —— 了解了（比 "OK" 更显专业）
· Will do. —— 好的，照办（回应任务指派）
· so everyone's on the same page —— 让大家信息一致
· no need to solve it here —— 站会只同步信息，深入讨论另外约时间

发音与连读提示

1. "going to" 在口语中读作 /ɡənə/（gonna）： "I'm gonna work on the search feature." 正式汇报中用 going to 完整读也没问题，但听力中必须认识 gonna。

2. "blocked on" 连读： blocked 结尾的 /t/ 很轻，几乎只做口型；on 弱读为 /ən/。读作 "blockt-on" 一气呵成。

3. 意群停顿： "Yesterday, / I finished implementing the login API." 逗号处停半拍，句末降调，显得从容不慌。

练习任务

  • 跟读：把上面 13 个句型每句大声读 3 遍，先慢速读准，再用正常语速。
  • 替换造句：把例句中的功能名换成你项目里的真实任务，说出你「真实的昨天和今天」各 3 句。
  • 模拟汇报：设定 timer 60 秒，用三段式完成一次完整的自我站会，录音。
  • 回听：重点检查：有没有说出来才卡壳的词？把它写下来，明天站会前再读一遍。
